# Player 参数与通道预览——M5-04 首个切片

[English](./player-parameters.md) | 简体中文

Player 打开标准 `.mix` 文件及内置棋盘格、釉面陶瓷、皮革和木材样例。控件来自已安装 Rust 运行时验证后的 `exposedParameters` 元数据：整数／浮点范围、确切枚举选项，以及颜色的四个数值 RGBA 分量。源码默认值和有效值均由运行时提供。无效源码不会显示前一材质的绑定。用户文件原始字节保持不变。

## 使用

1. 选择材质样例或打开 `.mix` 文件。元数据与验证会加载 WASM；这些操作不获取 GPU。
2. 选择尺寸，点击 **Initialize WebGPU**，再点击 **Render**。
3. 编辑公开参数或选择 **Preview channel**。GPU 已初始化时，有效变更会自动渲染。**Reset parameters** 移除全部覆盖，恢复源码／默认值。
4. 有效值标签显示最近通过验证的请求值。渲染期间，原图会明确标为过期；只有最新请求成功后才清除标记。
5. **Dispose GPU** 丢弃待处理请求，等待活动工作或未完成的设备获取结束，再释放设备。已有预览仍可查看。新设备需要显式初始化。

通道选项来自 Rust 材质元数据，包含文档化默认值。画布显示返回 RGBA8 字节的副本。颜色已由引擎执行 sRGB 转换；标量和法线字节直接作为数据预览显示。Player 不执行第二次转换或法线归一化。画布显示不是 PNG 导出，也不证明所有 alpha 值都无损。

## 请求所有权

`src/latest.ts` 持有一个活动渲染及最多一个可替换待处理请求。请求捕获原始字节、尺寸、通道与嵌套覆盖值。快速编辑替换待处理项，不取消已接受的 GPU 工作。过期成功／失败及重复 Promise 完成不能更新当前界面。无效编辑清空待处理项，并使活动结果过期。最新失败保留原图，同时显示过期标记和结构化诊断。

源码读取与 GPU 获取各自具有独立代次。较慢的旧文件不能替换较新的源码。关闭立即使渲染结果失效，等待迟到设备的清理，不能把销毁之后到达的 GPU 发布到界面。浏览器终止本身无法等待异步工作；合成 `pagehide` 测试验证已交付的生命周期事件，不保证进入 bfcache。

其他产品模块为 `runtime-client.ts`（显式加载与不可变请求捕获）、`controls.ts`（元数据驱动 DOM）、`files.ts`（原始字节）及 `preview.ts`（显示副本）。它们不实现节点目录、图验证器、编译器或像素渲染器。运行时 tarball 未变更，仍未发布。

## 验证

```bash
npm run check
npm run test:browser
node scripts/verify-isolated.mjs /absolute/path/to/OpenMixture
```

`check` 包含六项 Node 调度／快照测试、公开 TypeScript 检查与生产构建。浏览器套件覆盖三个材质的真实 128 × 128 参数变更，以及 baseColor／normal／roughness／height 预览，与同一浏览器中独立调用的公开运行时结果比较。还覆盖颜色／枚举控件、无效覆盖／源码、最新请求排队、真实设备丢失后保留过期预览、迟到文件读取、获取设备期间的 pagehide，以及 390 像素布局。仅测试使用的映射 Promise 屏障控制完成时序，GPU 操作与像素仍是真实结果。

macOS 隔离步骤要求干净的已提交产品树，并拒绝读取两个原始检出；见 [M5-02／M5-03 验证](./m5-02-03.zh-CN.md)。接受运行时保留确切源码／包身份及已检查截图。这些消费者像素检查不替代 M5-05 原生／浏览器质量比较或冻结的 1K 容差。
