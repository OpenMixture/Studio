# M5-02／M5-03 浏览器与软件包验证

[English](./m5-02-03.md) | 简体中文

初始 Player 消费未变更的 `@openmixture/runtime@0.1.0-alpha.0` 归档。这些检查用于完成初始浏览器执行与打包消费者范围；三材质质量、完整 Player 流程及正式浏览器 CI 矩阵仍属于 M5-04／M5-05。不要求先发布到 Registry。

## 浏览器检查

```bash
npm ci
npm run check
npm run test:browser
```

生产测试构建运行于 `/player/`。`tests/lifecycle.spec.ts` 通过仅测试使用的平台包装观察真实 Chromium 设备获取、错误作用域、映射与清理。它只导入已安装 SDK 的公开入口；普通产品构建不含探针。

- 在两次渲染之间以及读回边界销毁真实设备。验证结构化丢失、保留首个读回失败、跟踪的实时分配字节归零、作用域平衡、清理及已返回像素所有权。显式创建新设备后必须成功渲染。
- 对真实暂存缓冲区请求不对齐映射，产生实际 WebGPU 验证失败。验证清理、后续成功渲染，以及另一失败渲染结束期间的销毁行为。
- 加载八个独立运行时模块，每个创建一个设备并渲染四次棋盘格。验证 32 份每次调用分配清理报告、每设备一个棋盘格缓存流水线、八次显式销毁，以及首次输出保留。
- 验证没有未捕获 GPU 错误和未处理页面失败。按缓冲区身份统计读回解除映射：uniform 上传缓冲区初始化也会解除映射，不应混入读回清理。
- 单独注入 API 不可用、空适配器及设备获取拒绝，测试错误分类。这些不是成功 GPU 运行，也不是自发硬件故障证据。

设备丢失由真实 `GPUDevice.destroy()` 触发，浏览器交付的 `device.lost` 原因为 `destroyed`。这不证明驱动崩溃、物理 GPU 丢失或浏览器／标签页终止后的恢复。描述符核算不是物理 GPU 内存测量。有界棋盘格工作负载不替代 M5-05 的材质／生命周期压力覆盖。

## macOS 隔离消费

执行前先提交产品变更。如缺少锁定的 Chromium 二进制，先安装：

```bash
npx playwright install chromium
node scripts/verify-isolated.mjs /absolute/path/to/OpenMixture
```

将最后一个参数替换为需要禁止访问的引擎检出路径。脚本把干净的产品提交归档到新的临时目录，排除未跟踪文件，在其中执行安装、公开类型检查、生产构建与完整浏览器测试。macOS `sandbox-exec` 拒绝读取两个原始工作检出。负向探针验证拒绝生效，并验证子进程 PATH 中没有 `cargo`／`rustc`。Node 工具链、npm 依赖下载和已安装 Chromium 是前置条件，不是引擎依赖。

脚本打印输出目录，并写入 `receipt.json`，记录确切产品提交、源码归档、软件包／锁／夹具摘要及命令结果。完整命令日志与 Playwright 报告属于临时输出。将必要结果与附件保留在新的日期证据记录中；不覆盖初始浏览器检查点。其他主机使用普通浏览器步骤；本文件系统访问拒绝步骤仅支持 macOS，不代表可移植的浏览器 CI 环境。
