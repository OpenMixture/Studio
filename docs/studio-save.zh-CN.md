# Studio 历史、绑定与保存 — STUDIO-04

[English](./studio-save.md) | 简体中文

## 使用流程

打开 `/player/studio.html`。**Undo** / **Redo** 恢复材质命令、未完成数值文本和布局变更。历史最多保留 100 个命令；同一参数从开始输入到失焦计为一个命令，一次指针拖动计为一个命令。键盘布局步进分别记录。撤销后新编辑会清空重做分支。文本／选择控件外，Ctrl/Cmd+Z 撤销、Ctrl/Cmd+Shift+Z 重做；输入控件保留原生文本快捷键。历史仅在会话中保留，成功打开另一材质时重置。

选择节点，输入 **Public ID**，选择参数并点击 **Add public binding**。**Remove** 删除绑定。Rust 验证标识、重复绑定和目标。无效草稿仍可编辑与撤销，但不能保存或渲染。删除节点会原子移除其关联边和绑定；撤销一并恢复它们及布局位置。

**Save material .mix** 将确切的创作字节交给 Rust 验证后启动下载。未改变的材质保留打开时的原始字节；编辑后的序列化保留完整 JSON 值和数值词法文本。预览覆盖不会成为创作默认值。下载检查点独立于布局。**Discard material edits** 返回上次材质检查点（未保存新文档则为初始模板）；该操作可撤销。**Download original .mix** 始终返回本次会话打开时的字节。

**Save layout** 独立下载位置和视口，携带当前有效材质确切字节的 SHA-256 及节点标识。请同时保存匹配的材质。材质编辑会改变附属文件身份，即使位置未变也需重新保存布局。重新打开该材质后使用 **Load layout**。两种保存均支持编辑后的材质。移动布局不会使材质变为未保存。撤销回任一保存检查点会清除对应未保存状态。缺少布局时使用默认位置；损坏或不匹配的附属文件保留当前位置，不会改变材质语义。文档或布局发生变化后，过期的附属文件读取／保存被丢弃。

## 恢复与边界

打开文件或新建模板时，先完成字节准入、无损传输及图准备，再替换会话。准入失败会保留当前源码、字段、位置和历史。成功替换前，未保存工作需要确认。文件读取期间的创作编辑会使该读取失效。新模板初始为未保存；打开已有文件建立干净检查点。新建／打开使较早渲染结果失效，不取消 GPU 工作。

材质与布局下载失败均保留草稿及保存检查点。检查点表示浏览器已接受启动下载；页面无法验证磁盘写入完成，也不能检测用户在浏览器下载界面取消。必要时再次保存。关闭页面后不提供自动持久化恢复；未保存工作会触发浏览器离开提醒。

已安装归档、依赖及材质 schema 均未改变。产品历史保留传输快照，不实现渲染器或验证器。GPU 初始化／释放仍须显式操作；有效撤销／重做只调度最新预览，无效草稿阻止旧结果和 PNG 导出。

## 验证

```bash
npm run check
npm run test:browser
npm run test:deployment
```

测试集包含 20 项 Node 测试和 52 项浏览器用例。新增用例覆盖有界／合并历史、原子删除恢复、无效输入与重复绑定、独立检查点、未修改文件逐字节保存、棋盘格／陶瓷／皮革／木材编辑后保存重开、数值文本保留、匹配布局、下载／导入失败、取消新建／打开及过期读取。真实 GPU 读回屏障验证撤销的新鲜度；保留现有 GPU、Player 和生命周期测试。正常生产部署会保存并重开编辑后的棋盘格，比较其像素。

[证据](./evidence/studio-save/README.zh-CN.md)分别记录已测修订、环境及远端集成。STUDIO-01 至 STUDIO-05 已在[记录的保存文件矩阵](./evidence/studio-qualification/README.zh-CN.md)内完成；集成及更广验收仍单独处理。这不代表发布运行时、将产品部署到公网或建立更广浏览器支持。
