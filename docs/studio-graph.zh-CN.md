# Studio 只读源图视图

[English](./studio-graph.md) | 简体中文

## 打开与查看

运行现有产品：

```bash
npm ci
npm run dev
```

打开 `/player/studio.html`，或在 Player 导航选择 **Studio graph**。生产构建同时包含 `/player/` 和 `/player/studio.html`；两个入口使用相同静态主机和包内相对路径 WASM。不需要新依赖或运行时归档。

在 Source 面板选择棋盘格、釉面陶瓷、皮革、木材或用户 `.mix`。图显示创作节点（包括合法的未连接节点）、ID、类型／版本及目录端口。选中节点可查看创作／默认参数值、输入连接／默认值、输出类型和公开绑定。图来自验证后的源文档，不来自优化执行 pass。查看图不获取 GPU。

拖动节点改变位置，拖动背景平移。使用 **Fit graph**、**Center selected** 及缩放按钮导航。Selected node 列表可访问所有节点，包括屏幕外节点。Tab 聚焦节点后用方向键移动；聚焦画布后用方向键平移。Shift 增大移动步长；`+`/`−` 缩放，Home 适配整图。这些操作仅改变布局。

图下方保留现有预览控件：显式初始化 WebGPU、选择尺寸／通道、修改公开预览覆盖、渲染和下载 PNG。检查面板始终显示创作值；预览覆盖不改变图文档或原文件下载。两个入口共用一个活动／一个最新待处理请求调度器、过期结果规则和显式释放。GPU 失败后仍可查看源图。

## 源与布局契约

`src/source-graph.ts` 先将确切输入字节交给已安装 Rust 验证器。仅接受的输入才解码并投影用于展示。原生 JSON reviver source context 保留数值词法文本，包括 JavaScript 数值会舍入的小数位。目录默认值和端口／参数契约来自 `getNodeCatalog()`。这是展示投影，不是图验证器或编辑后文档序列化器。缺少数值 source context 的浏览器会收到投影错误；此功能仅在记录的 Chromium 环境验收。

`Download original .mix` 原样返回保留的输入字节，即使已移动节点、加载布局、修改预览覆盖或释放 GPU。无效输入清空图并禁用其下载控件；重复键和无效 UTF-8 不会通过规范化变成可接受材质。原有 Player 持续把相同字节交给 Rust。不包含材质编辑或改写 `.mix` 保存。

**Save layout** 下载版本 1 的 `.mix.layout.json` 伴随文件，包含确切源 SHA-256、节点位置和视口。节点标识及摘要将布局绑定到单一源；选择仅存在于会话内。重新加载同一源时先使用默认布局，直到显式加载伴随文件。布局缺失无害；损坏、超限（超过 4 MiB）、版本错误或不匹配的布局会回退到默认位置并显示提示。坐标和缩放限制仅约束产品布局。布局从不传给渲染器。

移动／平移／缩放／重置使布局标为未保存。下载或成功加载布局清除此标记；下载表示浏览器已收到文件，不证明已持久保存到磁盘。打开另一材质或离开页面会提示未保存布局。迟到的源／布局读取不能替换较新输入或布局变更。临时下载 URL 会撤销；仅保留当前图、布局和原始字节，无撤销历史。

## 里程碑边界

本切片交付 STUDIO-02 和 STUDIO-01 的只读子集：独立入口、字节优先验证、确切原文件下载、源图投影、布局归属及共享 Player 预览。无需修改引擎包即可解决投影需求。STUDIO-01 的创作序列化、编辑历史上限及新建文档流程仍是 STUDIO-03/04 前置条件；只读展示传输不需要它们，也不声称它们已完成。[MVP 计划](./studio-mvp.zh-CN.md)记录这一明确的顺序细化。

## 验证

```bash
npm run check
npm run test:browser
npm run test:deployment
```

检查覆盖 12 项 Node 测试和 35 项真实 Chromium 浏览器用例。七项 Studio 用例覆盖四个源图无 GPU 查看、目录详情、未连接节点、确切数值文本、原始字节下载／拒绝、键盘／拖动布局、伴随文件往返／失败、替换竞态，以及三种材质 × 四个 128 × 128 通道 PNG 与独立已安装运行时调用的比较。正常生产部署检查验证两个入口、真实棋盘格渲染／下载、确切原文件、WASM MIME 和测试页面缺席。

[2026-09-16 证据](./evidence/studio-graph/README.zh-CN.md)记录实际已测修订、浏览器／OS／适配器／flags、隔离消费者和 CI 状态。类型／构建检查、浏览器执行、隔离验收和远端 CI 分别记录。M5 已保留的原生／浏览器 1K 验收未变；本切片不声称新增 1K 原生验收或更广浏览器／硬件支持。
