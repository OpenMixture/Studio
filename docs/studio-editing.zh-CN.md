## 使用流程

打开 `/player/studio.html`。加载样例或有效 `.mix`，或用 **New checker material** 创建已验证的棋盘格连接输出文档。导入验证与编辑不获取 GPU。`/player/` 的 Player 保留原有字节保真流程。

在 **Author material** 中选择目录节点类型并点击 **Add node**。ID 按类型生成且不重复。选择图节点或通过 **Edit node** 编辑整数、浮点、枚举或四分量颜色参数。文本数值字段保留小数／指数词法文本，由 Rust 决定是否满足参数契约。**Use default** 删除该参数的创作覆盖。

选择 From node / Output port 与 To node / Input port，然后点击 **Connect ports**，替换目标输入的当前连接。**Disconnect input** 删除该连接。**Delete selected node** 以一次文档命令删除节点、所有关联连线及其公开绑定。无关节点、连线、绑定和源字段保持原值。创建／编辑绑定仍属后续批次。

Rust 诊断在编辑控件旁显示可用的节点、端口和参数标识。被报告的节点会高亮，并可从诊断中选中。无效草稿继续显示且可编辑，包括环、不兼容连接及缺失必需输入。不完整数值文本在切换节点后仍保留于字段内，整个草稿保持阻塞，直到修复、重置或随节点删除。不在 TypeScript 中复制验证器或渲染器。

显式初始化 WebGPU 后预览。有效创作编辑会自动预览；每次创作编辑清除临时 Player 式预览覆盖，避免其掩盖新源值。修改预览覆盖不会写入创作文档。无效编辑立即使待处理请求／当前导出资格失效。仅保留一个活动渲染和最新待处理快照。旧完成不能重绘或启用 PNG 导出；这是新鲜度失效，不是 GPU 取消。设备丢失保持错误，编辑仍可使用。

## 原始源、草稿与布局

本批次编辑仅保留在会话中。**Download original .mix** 始终返回打开的原始字节；新建棋盘格则返回初始模板。确认 **Discard material edits** 后恢复原始字节、参数字段及验证状态。打开另一材质／新模板或离开页面时，如材质／布局变更将丢失，会显示提示。撤销／重做、编辑后 `.mix` 保存及跨消费者创作验收仍属于 STUDIO-04/05。

布局保持在源外。编辑时保留既有位置，新建／重新创建的节点使用默认位置。结构变更使布局标为未保存。材质草稿变更期间禁用伴随布局加载／保存，因为本批次尚不能保存匹配的编辑后材质。丢弃材质编辑后可再次使用原始源对应的布局文件。移动节点不改变创作源字节。不保留编辑历史；状态仅包括一个原始检查点、一个当前文档和逐字段草稿文本。

## 文档传输契约

`src/document.ts` 无需新增引擎包即可解决 STUDIO-01 传输前置条件：

1. 将确切输入字节交给已安装 Rust 运行时验证后，才解析用于编辑。无效 UTF-8、重复键、不支持的源和损坏数值输入不能通过 JS 规范化变成有效输入。
2. 保留原始字节，投影完整 JSON 对象，包括界面未使用的字段。原生 JSON reviver source context 将每个数值词法文本保存在 `NumberToken` 中；字符串、数组、对象、布尔值和 null 保持 JSON 值。不具备该能力的浏览器不启用编辑。
3. 产品命令仅修改其持有的字段。序列化递归输出 JSON，不通过 JavaScript 数值转换处理 token，从而保留未编辑值和数值词法文本。仅在发生创作编辑后，空白和字符串转义形式才可能变化。未编辑文档与丢弃编辑恢复确切原始字节。类似原型属性的键作为普通自有数据属性处理。
4. 渲染前由 Rust 验证确切生成的候选字节。图投影可显示无效创作候选，但不认证其有效性。数值词法错误属于编辑器传输错误；范围／类型／图诊断来自 Rust。不完整文本不会回退到渲染前一个有效文档。

目录与材质格式仍由已安装的 `@openmixture/runtime@0.1.0-alpha.0` 持有。归档和依赖未变。新棋盘格使用目录版本构造普通源输入，不替代节点实现。不虚构公开图修改或引擎序列化 API。撤销／历史上限及最终保存文件契约留在 STUDIO-04；本批次明确保留零条撤销记录。
