Try OpenMixture Studio
试用材质编辑器

External trial using the accepted npm runtime 0.1.0-alpha.0. Qualification covers the recorded desktop environments; this is a prerelease, and human feedback is still being collected.
本次试用使用已验收的 npm 运行时 0.1.0-alpha.0。验收限于记录的桌面环境；当前为预发布版本，真人反馈仍在收集中。

Open Studio / 打开编辑器 Open Player / 打开播放器 Send feedback / 提交反馈

Allow about 20 minutes. Use a desktop browser with WebGPU; start at 128 × 128. Do not enable experimental GPU flags. If rendering fails, record the diagnostic and continue editing and saving.
预留约 20 分钟。使用支持 WebGPU 的桌面浏览器，从 128 × 128 开始，不开启实验性 GPU 参数。若渲染失败，记录诊断后继续编辑和保存。

  1. Create a material and add a checker node.
    新建材质，添加 checker 节点。
  2. Connect the checker output to the material base-color input.
    将 checker 输出连接到材质 base-color 输入。
  3. Edit a parameter, enter an invalid value, then find the diagnostic and repair it.
    修改参数，输入无效值，找到诊断并修复。
  4. Undo and redo your change.
    撤销并重做修改。
  5. Initialize WebGPU, render, switch channels and download a PNG.
    初始化 WebGPU，渲染、切换通道并下载 PNG。
  6. Save the material as a .mix file. Layout is saved separately.
    将材质另存为 .mix 文件，布局单独保存。
  7. Open Player in a new tab, load the saved .mix and compare its preview. Dispose the GPU in both tabs. Reopen the file in Studio to check the graph.
    在新标签页用 Player 打开刚保存的 .mix，对照预览。释放两个标签页的 GPU，再用 Studio 重开检查图。

For each step, report: independent, assisted, failed or not attempted. Include your browser/OS version, time spent and any help needed.
每项记录：独立完成、帮助后完成、失败或未尝试，附浏览器／OS 版本、耗时和获得的帮助。

GitHub feedback is public. Use samples or non-confidential material. You may send feedback to your inviter instead. There is no added feedback telemetry.
GitHub 反馈公开。请使用示例或非保密材质，也可直接向邀请人反馈。本试用不添加反馈遥测。
